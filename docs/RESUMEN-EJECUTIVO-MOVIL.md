# 📱 VERSIÓN MÓVIL - INSTRUCCIONES OPERACIONES (RESUMEN EJECUTIVO)

**Para compartir con técnicos, admin y colaboradores vía WhatsApp o impresión**

---

## 🔴 REGLAS DE ORO (MEMORIZAR)

```
1. Cuando EMPIEZAS trabajo → "EN PROCESO"
2. Cuando PARAS trabajo → "PAUSA"
3. Cuando RETOMAS trabajo → "EN PROCESO"
4. Cuando TERMINAS trabajo → "FINALIZADO"

Solo esos cuatro cambios. Nada más.
```

---

## 👨‍🔧 PARA EL TÉCNICO (3 MINUTOS DE LECTURA)

### Debes hacer:

✅ **Llego al cliente**
- Foto dirección
- Presento
- Marco **"EN PROCESO"** en app

✅ **Trabajo**
- Foto inicial
- Cada 1 hora: foto progreso
- Anoto cambios

✅ **Dejo pausa (otro día)**
- Foto estado actual
- Nota clara: "Falta [XXX], retomamos mañana"
- Marco **"PAUSA"** en app
- Aviso a admin por teléfono

✅ **Mañana retomo**
- Abro app
- Orden en PAUSA
- Marco **"EN PROCESO"** de nuevo
- Continúo

✅ **Termino**
- Foto final
- Firma cliente
- Reporte qué hiciste
- Marco **"FINALIZADO"** en app
- Espero revisión admin

### NO DEBES HACER:

❌ Cambiar estado sin razón documentada  
❌ Dejar orden sin marcar (EN PAUSA / FINALIZADO)  
❌ Tener 2+ órdenes EN PROCESO  
❌ Trabajar en grietas sin decirle a admin  
❌ Marcar FINALIZADO si no terminaste  

### Si hay problema:

🚨 **Llama a admin AHORA (no mensaje)**
- Explicas qué pasa
- Mandas foto
- Esperas instrucción

---

## 👨‍💼 PARA EL ADMIN (3 MINUTOS DE LECTURA)

### Debes hacer:

✅ **Mañana (8 AM)**
- Revisas órdenes AGENDADO
- Verificas que tengan técnico
- Si no → asignas ahora

✅ **Cada 2 horas**
- Ves órdenes EN PROCESO
- ¿Tienen fotos nuevas?
- Si no → llamas técnico

✅ **Cuando termina técnico**
- Revisas fotos (¿están bien?)
- Revisas reporte (¿está completo?)
- Revisas firma (¿cliente firmó?)
- **Si todo OK → "CERRADO"**
- **Si falta → devuelves a "EN PROCESO"**

✅ **Cierre (5 PM)**
- Ordenes cerradas hoy
- Técnicos sin movimiento
- Plan para mañana

### NO DEBES HACER:

❌ Dejar AGENDADO sin técnico más de 2 horas  
❌ EN PROCESO sin revisión más de 2 horas  
❌ PAUSA más de 3 días sin contactar  
❌ FINALIZADO sin revisar  
❌ Perder rastro de órdenes  

### Si problema:

📞 **Contactas técnico AHORA**
- Explicas qué necesitas
- Das instrucción clara
- Esperas confirmación

## 🆘 CASOS RÁPIDOS

### "Se me enfermó el técnico"
1. Técnico marca PAUSA
2. Admin busca otro técnico
3. Nuevo técnico retoma desde fotos anteriores
4. Continúa normalmente

### "Cliente pide cambio de técnico"
1. Técnico marca PAUSA
2. Admin habla con cliente (¿por qué?)
3. Si cambia → asigna otro
4. Nuevo técnico retoma

### "Cliente no estaba en casa"
1. Foto puerta
2. Marca PAUSA
3. Avisa admin
4. Admin reprograma

### "Encontré más trabajo de lo esperado"
1. Marca PAUSA
2. Fotos del problema
3. Llama admin AHORA
4. Admin coordina con cliente
5. Técnico continúa o no

### "Tengo problema técnico"
1. Marca PAUSA
2. Fotos claras
3. Llama admin AHORA
4. NO intentes arreglarlo solo

### "Cliente enojado"
1. Marca PAUSA
2. Retírate del conflicto
3. Llama admin AHORA
4. Admin habla con cliente
