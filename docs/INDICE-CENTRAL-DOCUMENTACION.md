# 📚 ÍNDICE CENTRAL - DOCUMENTACIÓN DE OPERACIONES

**Última actualización:** Mayo 2026

---

## 📖 DOCUMENTOS DISPONIBLES

### 1. 📋 INSTRUCCIONES COMPLETAS PARA COLABORADORES
**Archivo:** `INSTRUCCIONES-COLABORADORES-OPERACIONES.md`

**Para quién:** Todos (técnicos, admin, vendedores)

**Contenido:**
- Roles y responsabilidades de cada puesto
- Estados y transiciones detalladas
- Instrucciones paso a paso por rol
- Flujos diarios completos
- Checklist diarios (imprimibles)
- Preguntas frecuentes con respuestas

**Cuándo usar:** Referencia general, onboarding de nuevos colaboradores, dudas sobre procedimientos

**Tiempo de lectura:** 30-45 minutos

---

### 2. 🎯 GUÍA VISUAL Y FLUJOS RÁPIDOS
**Archivo:** `GUIA-VISUAL-FLUJOS-RAPIDOS.md`

**Para quién:** Técnicos y admin (principalmente)

**Contenido:**
- Flujos visuales con diagramas
- Tabla de estados rápida
- Transiciones permitidas ilustradas
- Checklists cortos e imprimibles
- Ejemplos prácticos de cómo documentar
- Respuestas a dudas rápidas
- Contactos de emergencia

**Cuándo usar:** Referencia rápida durante el trabajo, imprimir y llevar en bolsillo

**Tiempo de lectura:** 10-15 minutos

---

### 3. 🆘 CASOS ESPECIALES Y SITUACIONES COMPLEJAS
**Archivo:** `CASOS-ESPECIALES-COMPLEJOS.md`

**Para quién:** Admin (principalmente), técnicos para consultas

**Contenido:**
- Protocolo cuando técnico se enferma
- Cliente pide cambio de técnico
- Descubrimiento de trabajo adicional
- Cliente no está en casa
- Problemas técnicos durante el trabajo
- Cliente quiere negociar precio
- Accidentes o lesiones
- Órdenes atrasadas
- Problemas de garantía
- Cancelación de órdenes
- Criterios de escalada a gerencia

**Cuándo usar:** Cuando ocurren situaciones fuera del flujo normal, toma de decisiones complejas

**Tiempo de lectura:** 20-30 minutos (o consultar según sea necesario)

---

### 4. 📱 RESUMEN EJECUTIVO - VERSIÓN MÓVIL
**Archivo:** `RESUMEN-EJECUTIVO-MOVIL.md`

**Para quién:** Todos (especialmente técnicos en campo)

**Contenido:**
- Reglas de oro (4 puntos)
- Instrucciones técnico (resumidas)
- Instrucciones admin (resumidas)
- Estados permitidos
- Checklist diarios simplificados
- Casos rápidos con solución
- Contactos de emergencia

**Cuándo usar:** Referencia rápida en el celular, cuando no tienes tiempo para lectura completa

**Tiempo de lectura:** 3-5 minutos

## 🎓 CÓMO USAR ESTA DOCUMENTACIÓN

### Para Nuevo Empleado (Onboarding)

```
DÍA 1:
├─ Lee: INSTRUCCIONES-COLABORADORES-OPERACIONES.md (30 min)
└─ Descarga: RESUMEN-EJECUTIVO-MOVIL.md

DÍA 2:
├─ Lee: GUIA-VISUAL-FLUJOS-RAPIDOS.md (15 min)
└─ Practica: Pregunta dudas, observa a compañero

DÍA 3+:
├─ Consulta rápida según sea necesario
├─ Pregunta casos no previstos
└─ Después de 1 mes → lee CASOS-ESPECIALES-COMPLEJOS.md
```

### Para Técnico en Campo

```
ANTES DE SALIR:
├─ Revisa orden en app
└─ Consulta RESUMEN-EJECUTIVO-MOVIL si tienes duda

DURANTE TRABAJO:
├─ Revisa GUIA-VISUAL-FLUJOS-RAPIDOS en celular si necesitas
└─ Marca estados según checklist

EN CASO DE PROBLEMA:
├─ Llama a admin (teléfono)
├─ Admin consulta CASOS-ESPECIALES-COMPLEJOS
└─ Te da instrucción clara
```

### Para Admin

```
CADA MAÑANA:
├─ Revisa INSTRUCCIONES-COLABORADORES-OPERACIONES.md (sección Admin)
└─ Sigue checklist de GUIA-VISUAL-FLUJOS-RAPIDOS

DURANTE EL DÍA:
├─ Consulta GUIA-VISUAL-FLUJOS-RAPIDOS para transiciones
└─ Marca cambios en sistema

EN CASO ESPECIAL:
├─ Consulta CASOS-ESPECIALES-COMPLEJOS.md
├─ Sigue protocolo indicado
└─ Documenta en sistema
```

### Para Gerencia

```
REVISIÓN GENERAL:
├─ Lee: INSTRUCCIONES-COLABORADORES-OPERACIONES.md
└─ Lee: CASOS-ESPECIALES-COMPLEJOS.md

SUPERVISIÓN:
├─ Revisa checklists completados
├─ Verifica marcas de estado en sistema
└─ Resuelve escaladas según protocolo
```

## 🎯 OBJETIVOS DE LA DOCUMENTACIÓN

```
✅ Claridad: Cada colaborador sabe exactamente qué hacer
✅ Consistencia: Todos siguen el mismo proceso
✅ Rapidez: Referencia rápida cuando se necesita
✅ Escalabilidad: Funciona con 2 técnicos o 20 técnicos
✅ Documentación: Todo queda registrado en sistema
✅ Satisfacción: Cliente sabe qué esperar
```

---

## 💡 PRINCIPIOS FUNDAMENTALES

```
1. UN ESTADO A LA VEZ
   └─ Cada orden tiene UN estado en todo momento

2. TRANSICIONES CLARAS
   └─ Solo estados permitidos, cambios documentados

3. COMUNICACIÓN CONTINUA
   └─ Técnico informa a admin regularmente

4. DOCUMENTACIÓN TOTAL
   └─ Fotos, notas, horas, todo en sistema

5. SUPERVISIÓN ACTIVA
   └─ Admin revisa cada 2 horas máximo

6. CIERRE DEFINITIVO
   └─ Orden no se abandona sin estado final claro
```
