# 🆘 CASOS ESPECIALES Y SITUACIONES COMPLEJAS

Guía para resolver situaciones fuera del flujo normal.

---

## 1. TÉCNICO SE ENFERMA O NO PUEDE CONTINUAR

### Situación:
El técnico tiene una orden asignada pero se enferma, tiene accidente, o alguna emergencia personal.

### ¿QUÉ DEBE HACER EL TÉCNICO?

**PASO 1: INMEDIATAMENTE (en el momento)**
```
SI ESTOY EN EN PROCESO:
  └─ Llamo a admin por teléfono (NO solo mensaje)
  └─ Informo que no puedo continuar y por qué
  └─ Digo dónde estoy (aún con cliente o ya en casa)
  └─ Marco orden en PAUSA en la app
  └─ Escribo nota: "No puedo continuar por [RAZÓN]"
  └─ Subo fotos de estado actual
```

**PASO 2: DENTRO DE 1 HORA (si es posible)**
```
  └─ Envío comprobante si aplica (ej. receta médica)
  └─ Informo cuándo podré retomar (si es temporal)
  └─ Coordino con admin sobre lo que falta
```

### ¿QUÉ HACE ADMIN?

**PASO 1: INMEDIATAMENTE (cuando recibe llamada)**
```
✅ Verifica la razón (enfermedad, accidente, etc.)
✅ Acepta la pausa con causajustificada
✅ Revisa nota en la app
✅ Verifica que haya fotos de respaldo
✅ Estima cuánto trabajo falta
```

**PASO 2: EN LOS PRÓXIMOS 30 MINUTOS**
```
✅ Busca otro técnico disponible
✅ Le explica la situación y lo asigna
✅ Le envía todas las fotos y notas del anterior
✅ Lo instruye sobre qué debe hacer
```

**PASO 3: CONTINUA MONITOREANDO**
```
✅ Nuevo técnico marca EN PROCESO
✅ Admin revisa progreso regularmente
✅ Si hay problemas → apoya al nuevo técnico
```

## 2. CLIENTE PIDE CAMBIO DE TÉCNICO

### Situación:
El cliente no está satisfecho con el técnico asignado y pide cambio.

### Nivel 1: PROBLEMA LEVE (cliente no se siente cómodo)

**Técnico hace:**
```
1. NO se enoja ni discute
2. Marca orden en PAUSA
3. Llama a admin: "Cliente pide cambio de técnico"
4. Deja todo documentado y limpio
5. Espera instrucción de admin
```

**Admin hace:**
```
1. Habla con cliente: "¿Cuál es el problema exacto?"
   └─ Si es por comunicación → intenta resolver
   └─ Si es por desconfianza → cambia
   └─ Si es por falta de conocimiento → envía especialista

2. Si decide cambiar:
   ├─ Desasigna técnico anterior
   ├─ Asigna nuevo técnico
   ├─ Copia todas las notas y fotos
   ├─ Nuevo técnico marca EN PROCESO
   └─ Continúa trabajo

3. Si decide NO cambiar:
   ├─ Habla con cliente explicando
   ├─ Técnico original continúa
   ├─ Aumenta supervisión de admin
   └─ Verifica satisfacción al terminar
```

### Nivel 2: PROBLEMA GRAVE (cliente enojado, situación tensa)

**Técnico hace:**
```
1. Conserva la calma
2. Marca PAUSA
3. Se retira del lugar si hay conflicto
4. Avisa a admin AHORA (llamada, no mensaje)
5. NO intenta convencer al cliente de nada
```

**Admin hace:**
```
1. Contacta cliente personalmente
   └─ "Entiendo que hay inconformidad"
   └─ "Vamos a encontrar la mejor solución"

2. Evalúa la situación:
   ├─ ¿Es por técnico?         → Cambia técnico
   ├─ ¿Es por expectativas?    → Clarifica con cliente
   ├─ ¿Es por material/costo?  → Ajusta orden
   └─ ¿Es por comportamiento? → Atiende disciplina

3. Toma decisión y notifica:
   ├─ Técnico original
   ├─ Cliente
   ├─ Nuevo técnico (si aplica)
   └─ Gerencia (si es grave)

4. Reinicia proceso:
   └─ Nueva orden o mismo flujo
   └─ Mayor supervisión
   └─ Seguimiento post-trabajo
```

## 3. DESCUBRIMIENTO DE TRABAJO ADICIONAL NO PLANEADO

### Situación:
Durante el trabajo, el técnico descubre que hay más trabajo del que se presupuestó. Ejemplo: "Se necesita cambiar toda la instalación, no solo reparar".

### PROTOCOLO INMEDIATO (TÉCNICO)

**PASO 1: Detén el trabajo (PAUSA)**
```
❌ NO continúes con trabajo no presupuestado
✅ Marca orden en PAUSA
✅ Documenta qué encontraste
✅ Toma fotos claras del problema
✅ Escribe nota detallada
```

**PASO 2: Comunica al cliente**
```
DILE AL CLIENTE:
"Encontré un problema adicional que requiere 
[DESCRIPCIÓN]. Esto tendrá un costo de [ESTIMADO].
Necesito autorización de la empresa. Espera mientras 
coordino."

HAZLO EDUCADAMENTE, NO AMENAZANTE
```

**PASO 3: Avisa a admin AHORA**
```
📞 Llamada (no mensaje)
✅ Describo qué encontré
✅ Envío fotos
✅ Informo qué dijo el cliente
✅ Espero instrucción
```

### PROTOCOLO PARA ADMIN

**PASO 1: Evalúa el descubrimiento (RÁPIDO)**
```
Pregúntate:
├─ ¿Es real el problema encontrado?
├─ ¿Es razonable el costo estimado?
├─ ¿Es trabajo que DEBE hacerse o PODRÍA posponerse?
└─ ¿Tiene presupuesto el cliente?
```

**PASO 2: Comunica con cliente (AHORA)**
```
OPCIÓN A: Cliente aprueba costo
├─ Autoriza trabajo adicional
├─ Técnico continúa EN PROCESO
├─ Se registra el costo extra en sistema
└─ Se termina orden normalmente

OPCIÓN B: Cliente NO quiere gasto extra
├─ Se lleva a cabo SOLO lo presupuestado
├─ Lo adicional queda para orden de garantía
├─ O cliente puede pagar solo trabajo de hoy
└─ Orden se marca FINALIZADO con lo hecho

OPCIÓN C: Cliente quiere presupuesto
├─ Admin prepara presupuesto detallado
├─ Se envía a cliente
├─ Cliente tiene 24 horas para decidir
├─ Técnico deja orden en PAUSA
└─ Se continúa cuando cliente decide
```

**PASO 3: Comunica con técnico**
```
TÉCNICO, CONTINUARÁS PORQUE:
"Cliente autorizó trabajo adicional. 
Presupuesto: $XXX. Continúa en EN PROCESO."

TÉCNICO, NO CONTINUARÁS PORQUE:
"Cliente no autoriza trabajo adicional. 
Continúa solo con lo planeado. 
Terminan hoy y se cierra orden."
```

## 4. CLIENTE NO ESTÁ EN CASA

### Situación:
El técnico llega al lugar y el cliente no está, aunque tenía cita confirmada.

### TÉCNICO DEBE HACER

**PASO 1: Verificar que es la dirección correcta**
```
✅ Reviso dirección en app
✅ Pregunto a vecinos para confirmar
✅ Intento llamar al cliente
```

**PASO 2: Documental la situación**
```
✅ Tomo foto de la puerta/dirección
✅ Tomo foto de la hora en el celular
✅ Marca orden en PAUSA
✅ Escribo nota: "Cliente no presente a las XX:XX"
✅ Intento 2-3 llamadas
```

**PASO 3: Avisa a admin**
```
📞 Mensaje a admin con:
   ├─ Foto de dirección
   ├─ Hora exacta
   ├─ Qué intenté (llamadas, etc.)
   └─ Pregunta: "¿Qué hago?"
```

**PASO 4: Espera instrucción**
```
Posibles instrucciones de admin:

A) "Vuelve en 1 hora" 
   └─ Esperaré o haré otra orden, luego regreso

B) "Llama al cliente y reprograma"
   └─ Coordino nueva fecha, marca en sistema

C) "Regresa a base"
   └─ Cierro pausa, admin contacta cliente
```

### ADMIN DEBE HACER

**PASO 1: Contacta cliente (INMEDIATAMENTE)**
```
📞 Llamada o WhatsApp
"Hola [CLIENTE], el técnico llegó pero no 
te encontró en casa. ¿Dónde estabas? 
¿Confirmaste la cita para hoy?"
```

**PASO 2: Determina qué pasó**
```
CLIENTE OLVIDÓ → Reprograma próximamente
CLIENTE ENFERMO → Reprograma (deja por resolver)
CLIENTE NO QUERÍA → Cancela orden
CONFUSIÓN DE HORA → Reagenda con técnico hoy si es posible
```

**PASO 3: Ejecuta acción**
```
┌─ Si se reprograma:
│  ├─ Nueva fecha y hora en sistema
│  ├─ Notifica técnico
│  ├─ Cliente confirma
│  └─ Orden sigue en PAUSA hasta nueva fecha

└─ Si se cancela:
   ├─ Marca orden como CANCELADA
   ├─ Documenta razón
   └─ Cierra administrativamente
```

## 5. PROBLEMA TÉCNICO DURANTE EL TRABAJO

### Situación:
Mientras trabaja, el técnico descubre que el equipo/instalación existente está dañado, roto, o es diferente a lo esperado.

### REACCIÓN INMEDIATA (TÉCNICO)

```
❌ NO FUERCES NI IMPROVISES

✅ Detén el trabajo
✅ Documenta con fotos claras
✅ Escribe nota detallada
✅ Marca orden en PAUSA
✅ Llama a admin (teléfono)
```

### INFORMACIÓN PARA ADMIN

El técnico debe proporcionar:

```
□ ¿Qué encontraste exactamente?
□ Foto de la situación
□ ¿Es reparable o necesita reemplazo?
□ ¿Afecta el trabajo planeado?
□ ¿Necesita material especial?
□ ¿Pueden esperar los días que sea?
□ ¿Está el cliente presente?
```

### ADMIN ANALIZA Y DECIDE

```
OPCIÓN 1: REPARACIÓN SIMPLE
├─ Admin autoriza reparación
├─ Técnico obtiene materiales si falta
└─ Continúa EN PROCESO

OPCIÓN 2: REEMPLAZO DE EQUIPO
├─ Admin gestiona reemplazo
├─ Espera llegada de nuevo equipo
├─ Técnico continúa cuando llega
└─ Orden en PAUSA hasta tanto

OPCIÓN 3: TRABAJO FUERA DEL ALCANCE
├─ Admin contacta a especialista
├─ Técnico original pausa
├─ Especialista va a evaluar
└─ Se decide si continúa anterior o nuevo

OPCIÓN 4: CLIENTE DEBE DECIDIR
├─ Admin explica al cliente
├─ Le da opciones y costos
├─ Espera decisión del cliente
├─ Técnico pausa hasta resolución
```

## 6. CLIENTE QUIERE PAGAR MENOS O NEGOCIA PRECIO

### Situación:
El cliente al final dice que no puede pagar el precio acordado o quiere negociar.

### TÉCNICO DEBE HACER

```
❌ NO negoces precios (no es tu función)
❌ NO ofrezcas descuentos
❌ NO trabajos gratis

✅ Escucha al cliente
✅ Muestra empatía
✅ Documenta qué dice
✅ Marca orden en PAUSA si no puede pagar
✅ Avisa a admin
```

### ADMIN DEBE HACER

**PASO 1: Entiende la situación**
```
Llama al cliente y pregunta:
├─ "¿Cuál es el problema?"
├─ "¿No tenías presupuesto?"
├─ "¿El trabajo no te gustó?"
└─ "¿Qué podemos hacer?"
```

**PASO 2: Evalúa opciones**
```
OPCIÓN A: TRABAJO ESTÁ COMPLETO
├─ "El trabajo está listo"
├─ "El precio fue el acordado"
├─ "Necesitamos el pago para cerrar"
├─ Ofrece plan de pago si es posible
└─ Si no paga → genera venta pendiente

OPCIÓN B: CLIENTE TIENE RAZÓN (trabajo incompleto)
├─ Técnico continúa
├─ Se completa trabajo
├─ Luego se cierra

OPCIÓN C: PROBLEMA CON CALIDAD
├─ Se evalúa la calidad
├─ Si es culpa técnico → se arregla gratis
├─ Si es culpa cliente → se cobra igual
└─ Se deja documentado

OPCIÓN D: CLIENTE SIN DINERO AHORA
├─ Ofrece plan de pago (día siguiente, fin de mes)
├─ Toma nota de cliente (seguimiento)
├─ Técnico se retira pero orden no cierra
└─ Se finaliza cuando pague
```

**PASO 3: NUNCA HAGAS**
```
❌ Descuentos sin autorización gerencial
❌ Trabajos parciales sin aclarar
❌ Dejar orden sin cierre administrativo
❌ Promesas que no puedas cumplir
```

## 7. TÉCNICO TIENE ACCIDENTE O LESIÓN

### Situación:
El técnico se lesiona durante el trabajo (caída, cortada, etc.)

### INMEDIATAMENTE (TÉCNICO)

```
1. PRIMEROS AUXILIOS
   └─ Si es grave → llama ambulancia (911)
   └─ Si es leve → atiéndete

2. INFORMA A CLIENTE
   └─ "Tuve un accidente, necesito detener el trabajo"
   └─ Pide ayuda si es necesario

3. NOTIFICA A ADMIN
   📞 Llamada
   ├─ Informo que tuve accidente
   ├─ Nivel de gravedad
   └─ Ubicación actual

4. DOCUMENTACIÓN
   └─ Fotos del accidente si es posible
   └─ Nombres de testigos
   └─ Hora exacta
```

### ADMIN DEBE HACER

```
1. EVALUACIÓN INMEDIATA
   ├─ ¿Necesita ambulancia?
   ├─ ¿Está en condición de continuar?
   └─ ¿Puede salir del lugar solo?

2. SOPORTE INMEDIATO
   ├─ Si es grave → gestiona ambulancia
   ├─ Si es leve → autoriza que se atienda
   └─ Acompaña si es necesario

3. ORDEN SE PAUSA
   ├─ Se marca PAUSA
   ├─ Se documenta accidente
   ├─ Se asigna otro técnico si es urgente
   └─ Se sigue protocolo de seguridad

4. REPORTE A GERENCIA
   └─ Se notifica accidente
   └─ Se documentan circunstancias
   └─ Se evalúa si hay investigación necesaria

5. SEGUIMIENTO
   └─ Se verifica estado de técnico
   └─ Se coordina retorno cuando pueda
   └─ Se termina orden cuando sea posible
```

## 8. ORDEN LLEVA MÁS DE 3 DÍAS EN PAUSA

### Situación:
Una orden está en PAUSA más de lo esperado y se acumula el atraso.

### ADMIN DEBE REVISAR CADA MAÑANA

```
ÓRDENES EN PAUSA:
├─ Desde hace 1 día: Contactar técnico
├─ Desde hace 2 días: Presionar retoma
├─ Desde hace 3 días: ACCIÓN INMEDIATA
└─ Desde hace 4+ días: ESCALAR A GERENCIA
```

### PARA ÓRDENES EN PAUSA 3+ DÍAS

**Admin hace:**

```
PASO 1: Contacta técnico
┌─ "¿Qué pasó con orden [XXX]?"
├─ "¿Cuándo puedes retomar?"
└─ "¿Hay algún problema?"

PASO 2: Si técnico no puede continuar
├─ Busca razón (enfermedad, material, etc.)
├─ Asigna nuevo técnico
├─ Vieja orden en PAUSA histórica
└─ Nueva orden en EN PROCESO

PASO 3: Si técnico SÍ puede continuar
├─ Coordina fecha y hora de retoma
├─ Le recordamos que tiene orden antigua
├─ Se da por entendido: retomar mañana
└─ Se supervisa retoma

PASO 4: Contacta cliente
├─ "¿Cómo estamos con tu orden?"
├─ "¿Necesitas que retomemos?"
├─ "¿Hay cambios?"
└─ Actualiza información
```

### NUNCA DEJES ORDEN EN PAUSA SIN RESOLVER

```
Máximos aceptables:
├─ Trabajo parcial: 2 días en PAUSA
├─ Esperando cliente: 5 días en PAUSA
├─ Esperando material: hasta que llegue
└─ Esperando decisión: máx 3 días

Si pasas límite: ESCALA A GERENCIA
```

## 9. GARANTÍA: CLIENTE REPORTA PROBLEMA

### Situación:
Después de cerrada una orden, el cliente reporta un problema dentro del período de garantía.

### CLIENTE REPORTA (por teléfono/chat)

```
Dice: "El trabajo que hicieron no duró. 
Tengo problema con [XXX]. ¿Qué hago?"
```

### ADMIN RECIBE LA QUEJA

**PASO 1: Documentar**
```
□ ¿Cuál es exactamente el problema?
□ ¿Cuándo se manifiestó?
□ ¿Es dentro de período de garantía?
□ ¿Cliente tiene comprobante?
```

**PASO 2: Verificar garantía**
```
├─ ¿Está dentro del período? (normalmente 30-90 días)
├─ ¿Es por uso indebido del cliente?
├─ ¿Es por defecto del trabajo hecho?
└─ ¿Es por equipo dañado?
```

**PASO 3: Contactar técnico original**
```
"El cliente reporta problema con tu trabajo.
Necesito que vayas a revisar y solucionar.
[DETALLES DEL PROBLEMA]"
```

**PASO 4: Crear orden de garantía**
```
├─ Nueva orden en sistema
├─ Estado: GARANTÍA
├─ Asigna técnico original o especialista
├─ Técnico marca EN PROCESO cuando va
├─ Se repara/reemplaza lo necesario
├─ Se cierra como CERRADO
```

### TÉCNICO MANEJA GARANTÍA

```
PASO 1: Evalúa
├─ Reviso problema que reporta cliente
├─ Tomo fotos del daño
├─ Determino si es por mi trabajo o desgaste

PASO 2: Comunico a admin
├─ "Es por defecto de mi trabajo" (Se repara gratis)
├─ O "Es por uso del cliente" (Se cobra reparación)

PASO 3: Reparo o explico
├─ Si es defecto: reparo gratis
├─ Si no es: le explico al cliente que es por uso
└─ Admin decide si hacer descuento

PASO 4: Cierre
├─ Documento lo hecho
├─ Obtengo firma cliente
├─ Orden se marca CERRADO
└─ Cierre de garantía
```

## 10. CANCELACIÓN DE ORDEN

### Situación:
Una orden debe ser cancelada (cliente cambia de opinión, problema grave, etc.)

### ¿QUIÉN PUEDE CANCELAR?

```
✅ Admin sí puede
✅ Técnico puede solicitar (admin autoriza)
❌ Cliente no puede cancelar (admin lo hace)
```

### PROTOCOLO DE CANCELACIÓN

**PASO 1: Causa de cancelación**
```
Documentar claramente:
├─ Cliente cambió de opinión
├─ Problema insuperable
├─ Falta de pago
├─ Equipo no disponible
└─ Otra razón [ESPECIFICAR]
```

**PASO 2: Impacto**
```
Si está en PAUSA/EN PROCESO:
├─ ¿Se le cobra al cliente? (depende de avance)
├─ ¿Se le paga al técnico? (depende de acuerdo)
└─ ¿Se devuelve dinero? (si es necesario)
```

**PASO 3: Comunicación**
```
Admin contacta:
├─ Técnico: "Orden cancelada. No sigas con [XXX]"
├─ Cliente: "Orden cancelada por [RAZÓN]"
└─ Gerencia: Reporte de cancelación

Tech marca CANCELADO en sistema
Orden se cierra sin pagos pendientes
```

**PASO 4: Registro**
```
Documento en sistema:
├─ Razón de cancelación
├─ Quién decidió
├─ Qué trabajo se hizo (parcialmente)
├─ Dinero envuelto
└─ Resolución final
```

## RESUMEN DE ESCALADAS A GERENCIA

```
ESCALAD A GERENCIA CUANDO:
✅ Accidente o lesión grave
✅ Cliente muy enojado / problema serio
✅ Orden en PAUSA más de 5 días
✅ Cancelación por problema irreconciliable
✅ Costo extra mayor a 30% del presupuesto
✅ Técnico no puede continuar indefinidamente
✅ Equipo/material perdido o dañado
✅ Duda sobre normas o procedimientos
✅ Conflicto entre técnico y admin
✅ Cliente reporta problema de seguridad
```
