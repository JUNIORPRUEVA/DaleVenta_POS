Política de privacidad

Esta política explica cómo FULLTECH SRL trata la información usada por FullPOS Cloud para operar el punto de venta y los módulos empresariales asociados.

Datos que puede manejar la plataforma

  • Datos de cuenta: nombre, correo, teléfono, rol, permisos, estado de cuenta y empresa activa.
  • Datos del negocio: nombre comercial/legal, RNC o identificación fiscal, dirección, teléfono, correo, moneda, logo y parámetros de documentos.
  • Usuarios y empleados: perfiles, permisos, nómina, horarios, ponches, amonestaciones y documentos laborales cuando la empresa los registra.
  • Clientes: nombre, teléfono, dirección, notas, historial comercial y ubicación si la empresa la registra o la extrae desde enlaces de mapas.
  • Productos e inventario: códigos, nombres, precios, costos, categorías, existencias, movimientos e imágenes.
  • Operaciones: ventas, cotizaciones, compras, facturas, caja, gastos, cierres, pagos y documentos generados.
  • Archivos y fotos: comprobantes, imágenes de productos, evidencias, documentos y media cargada por usuarios autorizados.
  • Datos técnicos: tokens de sesión, identificadores de sesión, dirección IP, agente de usuario, logs de errores y registros de sincronización.

Uso de cámara, archivos y ubicación

La app incluye funciones para seleccionar o capturar imágenes, cargar archivos y trabajar con mapas/coordenadas. Estos datos se usan solo cuando el usuario o la empresa los registra dentro de módulos como productos, clientes, contabilidad o servicios.

Autenticación y contraseñas

La implementación del backend usa hashes de contraseña con bcrypt. Las contraseñas no deben almacenarse en texto plano. Las sesiones usan tokens y pueden ser revocadas por seguridad o eliminación de cuenta.

Finalidades

Usamos los datos para autenticar usuarios, operar el POS, sincronizar información, generar documentos, administrar inventario, dar soporte, mantener seguridad y cumplir obligaciones operativas razonables.

Almacenamiento y proveedores

La plataforma usa backend, base de datos, almacenamiento de archivos y servicios de infraestructura cloud. También puede usar almacenamiento local del dispositivo para sesión, caché y operación offline.

Seguridad, retención y eliminación

FullPOS Cloud aplica separación por empresa, autenticación con JWT, revocación de sesiones y controles de membresía/permisos. Conservamos datos mientras la cuenta o empresa los necesite para operar, soporte, respaldo técnico o cumplimiento aplicable. La eliminación de cuenta se inicia desde la app y se procesa en el servidor.
