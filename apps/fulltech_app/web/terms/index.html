Términos y condiciones

Estos términos regulan el uso de FullPOS Cloud, una plataforma de punto de venta y gestión empresarial ofrecida por FULLTECH SRL.

Naturaleza del servicio

FullPOS Cloud permite administrar ventas, caja, inventario, clientes, compras, cotizaciones, documentos, usuarios y otros módulos empresariales según la configuración contratada o habilitada.

Uso autorizado

El usuario debe usar la plataforma para operaciones legítimas de su empresa y mantener actualizada la información que registre.

Credenciales

Cada usuario es responsable de proteger su contraseña, dispositivos y sesiones. Debe reportar accesos no autorizados tan pronto los detecte.

Disponibilidad

FULLTECH SRL trabaja para mantener el servicio disponible, pero pueden existir interrupciones por mantenimiento, conectividad, proveedores o causas fuera de control razonable.

Respaldo y sincronización

La plataforma incluye funciones de sincronización y caché local. La empresa debe revisar sus cierres, documentos y respaldos operativos de acuerdo con sus procesos internos.

Mantenimiento

Podemos aplicar actualizaciones, correcciones o cambios técnicos para seguridad, estabilidad o mejora del servicio.

Suspensión

Podemos suspender cuentas por abuso, uso indebido, riesgos de seguridad, falta de licencia vigente o incumplimiento relevante de estos términos.

Propiedad intelectual y contenido

FullPOS Cloud, su diseño y software pertenecen a FULLTECH SRL o sus licenciantes. La empresa usuaria conserva responsabilidad sobre los datos, documentos, archivos, productos, clientes y demás contenido que registre.

Limitación razonable de responsabilidad

El servicio se ofrece para apoyar la gestión empresarial. El usuario debe validar información fiscal, contable, inventario, precios y documentos antes de usarlos para decisiones críticas o reportes externos.

Modificaciones, terminación y contacto

Podemos actualizar estos términos cuando el servicio cambie. Para consultas, escribe a ventas@fulltechrd.com o visita Contacto.
